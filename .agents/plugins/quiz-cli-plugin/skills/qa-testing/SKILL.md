# QA Testing 스킬

CLI 기능과 퀴즈 콘텐츠가 올바르게 연동되어 동작하는지 검증하기 위한 지침입니다.

## 1. 퀴즈 데이터 검증 (Data Validation)
- 퀴즈 데이터(JSON) 파일이 문법적으로 올바른지 파서를 통해 검사합니다.
- 누락된 필드(예: 정답이나 해설이 없는 경우)가 없는지 확인합니다.

## 2. CLI 동작 테스트 (Functional Testing)
- `uv run <script>` 또는 컴파일된 명령어를 직접 실행하여 CLI가 크래시 없이 실행되는지 확인합니다.
- 각 명령어 헬프 메시지(`--help`)가 올바르게 출력되는지 확인합니다.
- 퀴즈를 푸는 시뮬레이션을 통해 입력 처리, 정답/오답 판단 로직이 맞는지 체크합니다.

## 3. 결과 리포팅
- 테스트 중 발생한 오류나 UX 개선점은 `_workspace/qa_report.md` 형태의 파일로 기록하여 개발 에이전트가 쉽게 파악할 수 있도록 합니다.
- 재현 가능한 스텝(Reproduction Steps)을 반드시 명시합니다.
