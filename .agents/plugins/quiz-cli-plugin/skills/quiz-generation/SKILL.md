# Quiz Generation 스킬

부트캠프 학생들의 실력 테스트를 위한 고품질 파이썬 퀴즈를 생성하고 관리하는 지침입니다.

## 1. 퀴즈 형식 및 데이터 구조
- 퀴즈는 코드에서 파싱이 용이하고 데이터 구조를 명확히 표현할 수 있는 **JSON 형식**(`quiz.json`)으로 일관되게 저장합니다.
- 각 문제에는 최소한 다음 필드가 포함되어야 합니다:
  - `id`: 문제 고유 식별자
  - `chapter`: 관련 파이썬 챕터 (예: "Data Types", "Functions", "OOP")
  - `type`: 문제 유형 (multiple_choice, short_answer, code_snippet)
  - `question`: 문제 텍스트
  - `options`: (객관식인 경우) 선택지 배열
  - `answer`: 정답
  - `explanation`: 해설 (학생들이 틀렸을 때 학습할 수 있도록 상세히)

## 2. 출제 가이드라인
- **명확성**: 문제는 모호하지 않아야 합니다. "가장 적절한 것은?" 등 명확한 지시어를 사용하세요.
- **실전성**: 단순 문법 암기보다는 코드 결과를 예측하거나, 버그를 찾는 실전 형태의 문제를 권장합니다.
- **난이도 조절**: 한 챕터 내에서도 쉬운 문제부터 어려운 문제로 점진적으로 배치합니다.

## 3. 업데이트 방식
- 기존 퀴즈 파일이 존재한다면, 덮어쓰기 전에 기존 구조를 확인(read)하고 일관성을 유지하여 병합/추가합니다.
